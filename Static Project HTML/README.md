# Food Chain Website Project

## Overview
This is a modern, responsive website for a food chain business featuring vibrant colors and an attractive design. The website includes multiple pages with various sections to showcase the food chain's offerings, locations, and brand story.

## Project Structure

```
HTML Project/
├── index.html          # Homepage
├── about.html          # About page
├── menu.html           # Menu page
├── contact.html        # Contact page
├── locations.html      # Locations page
├── css/
│   ├── styles.css      # Main stylesheet
│   └── responsive.css  # Responsive styles
├── js/
│   └── main.js         # Main JavaScript file
└── images/
    └── icons/          # SVG icons for food categories
        ├── burger.svg
        ├── salad.svg
        ├── pizza.svg
        ├── dessert.svg
        └── drink.svg
```

## Features

- **Responsive Design**: Fully responsive layout that works on all device sizes
- **Modern UI**: Clean, vibrant design with attractive color scheme
- **Interactive Elements**: JavaScript-powered interactive components
- **Multiple Pages**: Complete website structure with various pages
- **SVG Icons**: Scalable vector icons for food categories

## Pages

1. **Home Page**: Features hero section, food categories, popular dishes, about preview, testimonials, app download section, and newsletter
2. **About Page**: Includes our story, mission, team, approach, and awards sections
3. **Menu Page**: Showcases different food categories with filtering options
4. **Contact Page**: Contains contact form, map, locations, and FAQ sections
5. **Locations Page**: Displays all restaurant locations with interactive map

## Usage

To view the website:
1. Open any of the HTML files in a web browser
2. For the best experience, start with `index.html`

## Customization

- **Colors**: Main color variables are defined at the top of the CSS file
- **Content**: Replace placeholder text and images with actual content
- **Functionality**: Extend JavaScript functionality as needed
